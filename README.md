WormForge is a Lua modding layer for WA 3.8.1 that lets you go past what the game can natively express: custom weapon behaviour, specialist worms and per-worm inventories, panel icons, truecolor sprites (including GIF support) and special effects, hurt rules, and whatever 
else you can imagine, really.

You don’t need to be a C++ reverse engineer or even a programmer to ship something. Non-coders can sketch weapons in the web editor; if you prefer to describe an idea and let an agent write the pack, the Lua API is intentionally small and example-driven. Drop a folder under Mods/, pick its weapons and add-ons for your profile in the in-game mod loader that launches on game start and you’re in. The module ships working examples — Highlander rules with a full custom weapon arsenal, turrets, swimming worms, worm toss, random sprite swaps, inventory demos, custom vehicles and much much more — so you can learn and/or copy.

Replays and WormNET are supported out of the box. Start from the site, check features, grab a build, enable an example, and see how far past “just another scheme” you can push a match or improve existing schemes.

INSTALL: Drop wkLua.dll next to WA.exe, Click "Check Online" and "Install". 

REQUIRES: Windows 10 or later (or Wine/CrossOver), Wormkit, use Direct3D 9 (shader). Some WormKit modules clash with WormForge: <a href="docs/requirements.md">Requirements and compatibility</a>

STATUS: Stable but replay backwards compability is not yet guaranteed.
